# UI icon sources

These SVGs come from the official Lucide repository:
https://github.com/lucide-icons/lucide/tree/main/icons

Refresh and Link were retrieved on 12 October 2026 for v1.2.1. The remaining
19 icons were retrieved on the same date for v1.2.2. Their original source
geometry is bundled here so builds do not fetch icon sources from the network.
The complete Lucide and Feather attribution is in LICENSE.txt.

History, Trash-2, and the Copy icon added in v1.2.3 use the Lucide 0.468.0 release sources:
https://github.com/lucide-icons/lucide/tree/0.468.0/icons

`tools/build_ui_icons.py` maps these SVGs to the application's existing icon
names, sets a shared 1.75 px stroke, and compiles antialiased 96 px alpha masks.
Tkinter displays tinted PNGs generated by the standard-library asset renderer.
Pillow and CairoSVG are required only to rebuild the masks.
